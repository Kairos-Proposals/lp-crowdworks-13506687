UNDERSTANDING / 案件理解

「作り替え」ではなく「着せ替え」。
その繊細さを理解しています。

今回ご依頼いただいている内容は、単なる新規テーマ制作ではなく、 診断ロジックや計測タグという“生きている資産”を壊さずに、 見た目だけを正確に入れ替える仕事だと理解しています。

01 / STRUCTURE

既存PHP+jQuery構造の継承

ビルダー不使用の自作テーマという前提を踏まえ、同じ設計思想・同じファイル構成でコーディングします。構造を乱す独自ルールは持ち込みません。

02 / FIDELITY

Figmaの再現度を最優先

デザインの意図を崩さず、余白・フォントサイズ・コンポーネントの挙動までピクセル単位で合わせ込みます。

03 / INTEGRITY

JS・タグ類への不介入

パラメータ引き継ぎ・診断フォーム・GTM/Site Kit/Clarity/Autoptimizeは一切変更せず、そのまま呼び出せる形で実装します。

04 / MOBILE

スマホ8割の実利用を前提

比較サイトの性質上、スマホでの比較・離脱・診断導線が重要と理解し、モバイルファーストで組み上げます。

VALUE / Kairosができること

金融系サイトの「正確性」に
耐えられるコーディング体制

比較サイト・診断サイトのような「数字の信頼」が問われる案件での制作実績を踏まえ、以下の価値をご提供します。

PX

Figma to Code の高精度再現

コンポーネント単位でFigmaを解析し、余白・行間・状態差分（hover/active）まで丁寧に実装します。

WP

オリジナルWPテーマ制作実績

ビルダーに依存しないPHP+jQueryベースのテーマ構築経験があり、既存コードの流儀に合わせた実装が可能です。

∎∎

計測・タグ環境を壊さない運用力

GTM/Clarity/Autoptimize等が入った本番環境への変更実績があり、既存の計測資産をそのまま維持します。

▤

モバイルファースト設計力

8割がスマホ閲覧という前提に合わせ、まずスマホ画面で崩れない設計から着手し、PCへ拡張します。

⏱

短納期への対応力

1週間という納期に対し、初日の構造共有から逆算したスケジュールで着実に進行します。

SCHEDULE / 進め方

1週間納期を前提にした
逆算スケジュール（目安）

ご相談のうえ調整可能ですが、まずは以下のような進行イメージをご提案します。

Day 1構造共有

既存テーマ構造・Figmaデータの受領

既存テーマのファイル構成、JS・タグ埋め込み箇所、Figmaデザインを確認し、不明点をすり合わせます。

Day 2-4コーディング

デザイン再現とテンプレート実装

既存構造をベースに、ヘッダー・診断フォーム周り・比較表・フッターなど主要テンプレートを実装します。

Day 5検証

JS・タグ動作確認とレスポンシブ確認

パラメータ引き継ぎ・診断フォームの動作、GTM等タグの発火を既存サイトと突き合わせて確認します。

Day 6-7納品

微調整・納品

フィードバックを反映し、テーマファイル一式を納品します。
